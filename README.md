# Bookshop Tracker

An Android application for tracking local bookshops, viewing bookshop details, and logging books bought at each bookshop.

## Features

- **Bookshops**: Add, edit, view, and delete bookshops (Name, Address, Description, Opening Hours, Ratings, New/Used book indicators).
- **Book Tracker**: Log books bought from each shop and mark whether you've read them.
- **Search & Filter**: Search bookshops and books in real time.
- **Navigation**: Bottom navigation bar with Home, Bookshops, Add Shop, and Settings tabs.
- **Settings**: App statistics and Dark Mode toggle.
